# ABC Write & Practice

Free kids' letter-tracing app. No login, no account, no ads. Works offline once opened (install it from the browser menu: "Add to Home screen").

Live: https://nidhiakaruna-lang.github.io/abc-write-practice/

Tabs: Trace, Draw, Quiz, Aa, 123, Missing, Spell, Say It, Phonics, Vowels, Maths, Paint, Play.
Languages: English, Francais, Deutsch (tap the globe in the top bar). Choice is remembered.
Spell, Say It, Phonics, Vowels and Maths teach English letters and words; the rest of the app speaks and shows the chosen language.

Files: index.html (page), css/ (styles), js/app1-9.js (loaded in order), sw.js (offline), manifest.webmanifest + icons/ (install).
